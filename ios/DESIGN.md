# Commonplace for iOS

This is an extension of the existing product, not a new visual identity. Source of truth: Android Theme.kt
and docs/STYLE.md. The user delegated implementation against those existing requirements.

- Warm paper, brown-black ink, one rubric-red interactive tint; named light/dark tokens adapt together.
- Literata for research headings and source reading; native text styles for controls and utility content.
- Native tab navigation for Ask, Library, History and Settings. Native lists, sheets, pickers and alerts.
- Evidence arrives before prose. Citation numbers open the original passage; full articles preserve credit/license.
- Underlined unverified passages use a visible explanatory label; neither color nor icon alone carries the meaning.
- Dynamic Type, light/dark appearance, text selection, system back gestures and at least 44 pt touch targets.
- Use SF Symbols. No invented illustrations, decorative gradients or web-shaped navigation chrome.
- Verify on simulator iPhone and iPad, including a large text size, then verify memory/gestures/performance on hardware.
